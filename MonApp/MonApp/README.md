# MonApp

MonApp is a React Native application that showcases user information with a visually appealing interface. The application features an image background, a profile image, and displays user details such as name and academic year.

## Features

- User interface built with React Native components.
- Image background for a modern look.
- Displays user profile information.

## Installation

To get started with MonApp, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/MonApp.git
   ```

2. Navigate to the project directory:
   ```
   cd MonApp
   ```

3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To run the application, use the following command:
```
npm start
```

This will start the Metro bundler. You can then run the app on an emulator or a physical device.
